Battery Management System (BMS) – Electric Vehicle

This project demonstrates the design of a basic Battery Management System
for an electric vehicle.

Features:
- Cell voltage monitoring
- Temperature sensing
- Over-voltage and under-voltage protection
- SOC estimation (basic logic)
- Fault detection and safety states

Technologies:
- Embedded C
- Microcontroller-based design (conceptual STM32)
- Sensors and ADC reading

This project was developed as part of my BSc Electrical & Electronics Engineering degree.
